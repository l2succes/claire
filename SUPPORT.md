# Support

Claire is alpha software. Please do not use it as your only messenger for high-stakes communication yet.

## Where to ask

- **Bugs:** GitHub Issues
- **How-to questions:** GitHub Discussions → Q&A
- **Ideas:** GitHub Discussions → Ideas
- **Plugins:** GitHub Discussions → Plugins
- **Self-hosting:** GitHub Discussions → Self-hosting
- **Security:** [SECURITY.md](SECURITY.md)

## What we cannot help with here

- Production credentials, Railway project access, or database proxies
- Recovering a leaked key — rotate it in your own project
- Unsupported privacy guarantees

Docs: https://github.com/l2succes/claire/tree/main/docs
