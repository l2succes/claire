# Desktop development

Desktop code lives in `apps/desktop/`. It hosts the shared Expo web client in Electron for macOS,
Windows, and Linux.

```bash
bun run dev:desktop
```

See [docs/DESKTOP_APP_IMPLEMENTATION_SPEC.md](../DESKTOP_APP_IMPLEMENTATION_SPEC.md) and [docs/COMPANION_APP_SETUP.md](../COMPANION_APP_SETUP.md).
