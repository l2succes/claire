Claire endpoint directory

Public URLs for Claire. Production and staging are strictly isolated. Internal services such as Postgres, Redis, Studio, bridges, and object storage are intentionally not listed.

Production LIVE

Real users and production data.

  • Website — useclaire.co Primary public website.
  • Website redirect — www.useclaire.co Permanent redirect to the primary website.
  • Claire API — api.useclaire.co Application API. Authentication is required for private routes.
  • API liveness — /healthz Non-sensitive load-balancer readiness result.
  • Supabase gateway — supabase.useclaire.co Public gateway only; Auth and API requests still require their normal credentials.

Staging PROVISIONING

Fixtures and opt-in testers only; never production data or credentials.

  • Website — staging.useclaire.co Tracks the main branch in Vercel.
  • Claire API — api.staging.useclaire.co Reserved. Available after the isolated staging API deployment and DNS/TLS verification.
  • API liveness — /healthz Reserved with the staging API endpoint.
  • Supabase gateway — supabase.staging.useclaire.co Live isolated Supabase gateway. Auth is invite-only and redirects are limited to staging origins.
Updated during infrastructure setup. Do not add direct links to private Railway services, database hosts, Studio, storage, Redis, Synapse, or bridge administration endpoints.
