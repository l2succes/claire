What “local” means today

Self-hosting keeps Claire’s message store on infrastructure you control. The original messaging networks still process their messages, and configured external AI providers may receive selected conversation content. We will not claim “never stored in the cloud” until desktop-only mode has passed its security and network-egress review.

* iMessage needs its Mac host available. Google Messages depends on the paired Android phone.

Before you begin

✓

About 10 minutes
Your data stays on infrastructure you control.

1

Install and start Claire

Clone the repository, install dependencies, and start the local stack.

TERMINAL 
git clone https://github.com/l2succes/claire.git
cd claire
bun run install:server && bun run install:client
bun run docker:up
bun run dev
2

Configure your environment

Copy both templates, then add your Supabase and Matrix credentials.

cp server/.env.example server/.env
cp client/.env.example client/.env

●When Expo shows a QR code, scan it with Expo Go—or press i for the iOS simulator.

Quick fixes

Docker services won’t start ＋

Check that Docker Desktop is running and ports 3001, 6379, and 8008 are available. Then run bun run docker:down before trying again.

The app can’t reach the server ＋

For a physical device, use your computer’s LAN IP in EXPO_PUBLIC_SERVER_URL. Localhost only works in the simulator.

WhatsApp isn’t connecting ＋

Open WhatsApp → Settings → Linked Devices, then scan the QR code Claire displays. Check docker logs claire-mautrix-whatsapp if pairing stalls.
