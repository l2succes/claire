PLUGIN PRODUCT SYSTEM / CONCEPT 01

Conversation in.
Useful action out.

Claire plugins connect the meaning inside a conversation to the tools where life and work happen. They can suggest, prepare, or complete an action—but only within permissions the user understands and controls.

Explore the library Read the implementation spec
THE SAFETY CONTRACT

Detection is not permission.

01Claire identifies a useful moment.
02The plugin drafts a typed action.
03The user reviews sensitive writes.
04Every result stays visible and reversible.
