# Developer quickstart

Claire’s website is a Next.js App Router application. The component kit and documentation live beside the public product pages so the reference cannot quietly drift away from the implementation.

## Start the website

```bash
cd website
bun install
bun run dev
```

The site runs at `http://localhost:3000` by default.

## Storybook

The same primitives used by the site are available in an isolated component workshop:

```bash
cd website
bun run storybook
```

Storybook runs at `http://localhost:6006`. New reusable components should include a story, keyboard states, and an accessibility pass.

## Information architecture

- Public product pages explain the customer promise and current availability.
- Developer references define layouts, states, and implementation rules.
- Components encode visual decisions once and are composed into pages.
- Root-level architecture specs remain the deep technical source while they are progressively converted to MDX.

## Migration rule

The legacy static reference has been migrated into `apps/website/`; preserve these routes, public assets, interactions, responsive behavior, and accessibility states when iterating on the site.
